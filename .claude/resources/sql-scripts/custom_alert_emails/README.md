# custom_alert_emails

HTML email notifications for SQL Server Agent jobs, sent through Database Mail.

| Script | What it does | Changes the server |
|---|---|---|
| [enable_database_mail.sql](enable_database_mail.sql) | Turns on `Database Mail XPs` with `sp_configure` | Yes |
| [dbo.usp_send_job_custom_email.sql](dbo.usp_send_job_custom_email.sql) | Creates `dbo.usp_send_job_custom_email`, which emails a formatted summary of a job's latest run | Yes |

Run them in order, after a Database Mail profile exists. Then call the procedure
from a final job step. For fleet-wide alerting, Data Eyes uses Grafana email instead
(see [monitor/README.md](../../../../monitor/README.md#alerting)).

## Where this fits

- Part of the script library under `.claude/resources/sql-scripts/`, routed by the `/sql-scripts` command.
- Nothing here runs on its own. A DBA, `/sql-scripts` or the `sql-server-dba` agent picks a script and runs it against a server in the fleet.
- A per-job alternative to Grafana email. Fleet-wide, the collector's `job_failed` check and the `SqlServerEvents` Grafana rule already alert on failed jobs.
